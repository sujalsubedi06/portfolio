# Getting Started

## Clone Repository

```bash
git clone https://github.com/sujalsubedi06/portfolio.git
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

# Available Commands

| Command | Description |

Create a `.env.local` file:

- API keys
- Access tokens
